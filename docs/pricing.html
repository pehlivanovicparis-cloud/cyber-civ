QUESTIONS, ANSWERED

What exactly am I buying?

Metered access to the CIV-GUIDE assistant API: ask about the civilizations, the governance mechanics, how to run the simulation, and licensing. Every response is grounded in the official CYBER CIV knowledge base — no hallucinations about the project.

How do I use my API key?

Send POST requests to /v1/chat/completions with Authorization: Bearer YOUR_KEY, exactly like the OpenAI API. The web chat on this site works too — paste your customer key instead of a provider key.

What happens if I hit my monthly limit?

You'll get a clear upgrade prompt instead of a cryptic error. Limits reset on the first of each month. Upgrade mid-cycle and your new quota applies immediately.

Can I cancel?

Yes, anytime from the Stripe customer portal. Your key stays active until the end of the billing period, then it's revoked automatically.

Is the simulation itself included?

The assistant API is what's metered. The simulation code stays under its proprietary license — running it commercially needs a separate written agreement. Ask us.
