Served locally? Run python3 -m http.server 8000 from the repo root and open http://localhost:8000/spectator.html while the sim runs — the page polls history.jsonl and memory/civ_memory/*.jsonl every 3 seconds. On GitHub Pages it loads the published snapshot in docs/ as a replay. Headlines appear only for generations recorded after the history log started carrying them (see cyber_civ.py); older rows show the world / country / risk instead.
