# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, **please do not open a public issue**. Report it privately so it can be addressed before disclosure.

**Contact:** Pehlivanovicparis@gmail.com

Please include in your report:
- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact if exploited
- Any suggested remediation (optional)

## What to Expect

- **Acknowledgment** of your report within 72 hours
- **Updates** as the issue is investigated and fixed
- **Credit** in the fix notes, if you wish to be named

## Scope

This policy covers the code maintained in this repository. If the vulnerability exists in an upstream project this work builds on, please also report it to the upstream maintainers.
